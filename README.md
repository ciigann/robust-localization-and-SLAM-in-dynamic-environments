# Робастная локализация и картирование при изменении состояния объектов в динамических сценах
## Проблематика
Необходимо разработать систему динамического SLAM с долговременной памятью состояний объектов, которая сможет отличать временно остановившиеся динамические объекты от статичных и обнаруживать перемещение ранее статичных объектов, сохраняя точность локализации и целостность карты.

## Актуальность
В задачах SLAM обычно отдельно рассматриваются распознавание динамических объектов и обновление карты при перемещении ранее статичных объектов. Существующие методы либо фильтруют движущиеся объекты при построении карты в динамической среде, либо отслеживают изменение положения статичных объектов в статичной сцене. При этом недостаточно исследован единый подход, способный одновременно отличать временно остановившиеся динамические объекты от действительно статичных и обнаруживать перемещение объектов, ранее считавшихся статичными. Объединение этих задач в одной системе позволит повысить робастность локализации, предотвратить загрязнение карты и обеспечить её корректное обновление в изменяющейся среде.
